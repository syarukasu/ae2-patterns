# Scope

Read docs/SPECIFICATION-v0.2.md and docs/ARCHITECTURE.md before edits.
This is an independent AE2 addon. Do not modify ACO, other mods, live packs,
server launchers or saved worlds as part of this project.

No executable composite patterns: the control advertisement must expand into
real, currently mounted source patterns before an executable plan is returned.
AE2 owns inventory simulation, missing, bytes, CPU submission and execution.
No direct item creation or extraction, independent committed branch inventories,
silent ratio normalization or stock-dependent route reordering.
STRICT never reassigns shares. The explicitly selected ADAPTIVE mode may reassign
shortfalls in stable registration order through isolated native AE2 trials, applying
only successful child diffs to the same parent simulation inventory.

Keep STRICT arithmetic shared between both loaders. Reject unsupported dynamic
patterns, unknown schemas, duplicate recipes and out-of-range native quantities.
Do not add compatibility for hypothetical unreleased schemas.

Before packaging: core tests, both loader builds, both isolated GameTests,
resource audit and git diff --check. Report GUI visual and live-pack acceptance
separately from build and GameTest evidence.
