# Asset and Integration Notice

Applied Energistics 2 is a required, separately distributed dependency. This addon references AE2's native terminal model and texture resource identifiers and reuses its runtime UI classes. AE2 model and texture files are not copied into the addon.

The two composite-pattern illustrations in `artwork/original` were supplied by the project owner. Runtime item textures are 16x16 nearest-neighbor reductions of those images.

The addon is independently maintained and is not an official Applied Energistics project.
